## 🚀 ¿Qué es Trigoou?

**Trigoou** es una aplicación web educativa diseñada para facilitar el aprendizaje de la trigonometría mediante demostraciones guiadas, representaciones gráficas, ejercicios interactivos y actividades de práctica.

Su propósito es que los estudiantes no se limiten a memorizar fórmulas, sino que comprendan las relaciones matemáticas que permiten demostrar una identidad trigonométrica.

La plataforma está orientada principalmente a estudiantes de **grado décimo**, aunque también puede servir como recurso de apoyo para docentes de matemáticas.

## ✨ Características principales

| Módulo | ¿Qué puedes hacer? |
|---|---|
| 📚 **Aprender** | Explorar identidades trigonométricas mediante explicaciones y demostraciones guiadas. |
| 🧭 **Círculo unitario** | Manipular ángulos, consultar valores trigonométricos y explorar ángulos notables. |
| 📈 **Gráficas interactivas** | Comparar expresiones trigonométricas mediante sus gráficas y tablas de valores. |
| 🧪 **Laboratorio trigonométrico** | Experimentar con identidades de suma de ángulos y ángulos dobles. |
| 🎯 **Practicar** | Resolver retos, organizar pasos de demostraciones, responder cuestionarios y resolver problemas. |
| 🧠 **Tarjetas de estudio** | Repasar conceptos y relaciones trigonométricas. |
| 🏆 **Mi progreso** | Consultar avances, historial de actividades y logros obtenidos. |
| 👨‍🏫 **Modo docente** | Preparar secuencias de clase, consultar rúbricas y gestionar ejercicios personalizados. |
| 📊 **Exportación de resultados** | Exportar información de progreso y evidencias en formatos disponibles en la aplicación. |

## 🛠️ Tecnologías utilizadas

El proyecto integra tecnologías web para ofrecer una experiencia interactiva:

- **HTML5:** estructura y organización del contenido.
- **CSS3:** estilos visuales, diseño adaptable y animaciones.
- **JavaScript:** lógica de interacción y funcionamiento de los módulos.
- **Plotly.js:** visualización de gráficas interactivas.
- **Math.js:** apoyo para operaciones y expresiones matemáticas.
- **Google Fonts:** tipografía de la interfaz.

## 💻 ¿Cómo ejecutar el proyecto?

Puedes explorar Trigoou directamente desde tu navegador, sin instalar un entorno de desarrollo complejo.

### Opción 1. Abrir localmente

1. Descarga o clona este repositorio.
2. Localiza el archivo `index.html`.
3. Ábrelo en un navegador moderno.
4. Explora los módulos disponibles.

Después, abre `index.html` en tu navegador.

## 🧩 Enfoque pedagógico

Trigoou busca conectar tres elementos fundamentales del aprendizaje matemático:

- **Comprensión conceptual:** entender qué representa una identidad trigonométrica.
- **Exploración visual:** relacionar expresiones algebraicas con gráficas y representaciones geométricas.
- **Práctica activa:** comprobar conocimientos, resolver problemas y analizar procedimientos.

La propuesta invita a experimentar, formular conjeturas y verificar relaciones matemáticas, convirtiendo el navegador en un espacio de exploración y aprendizaje.
