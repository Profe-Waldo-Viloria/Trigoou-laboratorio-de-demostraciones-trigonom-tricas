Trigoou: Laboratorio de Demostraciones e Identidades Trigonométricas

Este proyecto es una página web interactiva creada para apoyar el aprendizaje de las identidades trigonométricas y sus demostraciones.

Contenido

La página incluye ejercicios y explicaciones relacionados con:

- Identidades trigonométricas fundamentales.
- Simplificación de expresiones trigonométricas.
- Demostraciones paso a paso.
- Uso de razones trigonométricas y equivalencias.

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

Cómo usar el proyecto

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web.
3. Explora las secciones, ejemplos y demostraciones incluidas.

No se requiere instalar programas ni dependencias adicionales.
